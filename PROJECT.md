# Viber MCP для Debian / Hermes

Мета: швидка локальна взаємодія Hermes (або іншого MCP-клієнта) з Viber Desktop
на Linux через стандартний MCP stdio, без хмарного OCR і без доступу до ключів Viber.

## Definition of Done

- Вивчено вихідний код wawimundo/viber-mcp з прив'язкою до commit.
- Реалізовано Linux backend, діагностику, читання, навігацію, підготовку повідомлень
  та контрольоване надсилання з перевіркою адресата і захистом від повторів.
- Є відтворюваний Python-проєкт, тести небезпечних/помилкових сценаріїв,
  приклади конфігурації Hermes локально та через SSH.
- Перевірено справжній MCP handshake і доступні живі операції Viber.
- Чітко відділено перевірені можливості від неперевіреного надсилання/доставки.
  Зовнішнє тестове повідомлення потребує адресата, тексту та прямого погодження.

## Середовище, 2026-10-18

Хост розробки: Linux Mint 22.3 (Ubuntu/Debian family), X11, Python 3.12.
Viber встановлено у /opt/viber; база має не-SQLite заголовок.
xdotool, wmctrl, xclip, PyGObject/pyatspi та Pillow наявні; tesseract відсутній.
Конфігурацію Hermes не змінюємо без окремого погодження. Господар окремо доручив замінити Viber на VPS офіційним пакетом, зберігши профіль.
Окрема папка в наявному git workspace; приватні артефакти і runtime ігноруються.

## Уточнена вимога: лише збережені контакти

Господар обмежив адресатів справжньою адресною книгою Viber; новим/незбереженим
контактам повідомлення не надсилаємо. Додатковий критерій DoD: довести джерело
saved membership і стабільний зв'язок contact ID з активним чатом. Псевдоніми,
історія листування, поточний чат або збіг імені не є заміною. Дублікати імен та
неоднозначність мають блокувати запис. Поки ці докази відсутні, write capability
не вважається готовою і не вмикається в production.
