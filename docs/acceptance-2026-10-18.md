# Desktop Viber MCP — приймання 2026-10-18


Type: verified observation / decision
Operator цього тесту: Henelora. Джерело: live MCP tool results у розмові та підтвердження Господаря, що текст читається й усе видно.

- Пошук `find_contact` за двома псевдонімами повернув правильні збережені контакти. Початково інструмент був недоступний; після підключення перевірений реальними викликами.
- Послідовне відкриття двох тестових чатів, читання видимого тексту, створення точної української чернетки без надсилання та повернення до основного чату пройшли. Для цих двох контактів MCP повертав `header_verified: true`.
- Після повідомленої зміни обмежень перевірено прямий повний номер третього тестового адресата: open → draft → погоджений send → read-back. Після нової репліки виконано друге окремо погоджене надсилання з емодзі; обидва тексти підтверджені читанням історії. Господар підтвердив видимість і працездатність.
- Це доказ для протестованих адресатів, не для довільного номера. У відповіді open для третього адресата не було `header_verified`; сильну верифікацію заголовка для нього не заявляти.
- Не перевірено: незалежні delivery/read receipts, збереження чернетки після виходу, повна історія, структуровані автор/час/напрямок, медіа, паралельні виклики, безперервний моніторинг. Масив текстів не доводить автора кожного повідомлення.
- Старий висновок «лише один дозволений контакт» більше не описує перевірений стан. Негативний пошук контакту не означає відсутність номера у Viber.
- n8n/IBAN обговорено лише як можливий наступний напрям; рішення про впровадження немає, workflow/production не змінювались. Потрібні перевірка MCP transport/client, єдина черга для desktop, дедуплікація бізнес-подій і обробка невизначеного результату без сліпого повтору.
